# EDUPLAN C-3

Versión inicial funcional de una plataforma docente inspirada en la estructura general de un portal de herramientas pedagógicas.

## Incluye

- Panel de inicio.
- Planificación.
- Sesiones.
- Evaluación.
- Recursos.
- Biblioteca local.
- Generador pedagógico EDUPLAN IA.
- 8 áreas curriculares.
- **Arte y Cultura** incorporada.
- Persistencia de recursos mediante localStorage.
- Diseño responsive para PC, tablet y móvil.

## Ejecutar

No requiere Node.js.

Abre `index.html` en un navegador.

## Publicar en Vercel

1. Sube esta carpeta a un repositorio de GitHub.
2. En Vercel selecciona el repositorio.
3. No necesitas comando de build.
4. Publica.

## Próxima etapa

Para convertir el generador base en IA real, conecta un backend/API y no expongas la clave de la API en el navegador.

## Nota

Esta versión no contiene el código privado del sitio de referencia. Es una implementación independiente con una arquitectura y flujo similares, preparada para que se incorporen después las funciones específicas del proyecto original.
